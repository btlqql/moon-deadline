# 初审意见整改核对

依据用户提供的《MoonDeadline》初审回执：旧作品聚焦受限模型的离线分析、范围及生态增量不足、未完成基本 MVP；建议面向明确硬件平台实现 RTOS 核心/运行时，覆盖任务调度、上下文切换、时钟、同步通信与实际执行。

| 审核关注点 | 本次已交付 | 可核查证据 |
|---|---|---|
| 从离线分析转向执行系统 | 独立 PSP 任务栈、Cortex-M3 ARM ELF 从复位启动 | `ports/cortex-m3/`、`firmware/`、UART 启动与退出记录 |
| 任务调度 | 优先级抢占、同级轮转、阻塞/唤醒/退出、idle | `rtos/kernel.mbt`，QEMU 场景 1 |
| 上下文切换 | SVC 启动、PendSV 保存/恢复 R4–R11 与 PSP | `context.S`、寄存器 canary、150,012 次身份切换 |
| 时钟 | SysTick 驱动、延时、超时、32 位 tick 回绕语义 | 场景 1/4，回绕单元测试 |
| 同步 | 有界信号量、非递归锁、传递式优先级继承、循环等待拒绝 | 场景 2，继承链/超时/退出测试 |
| 通信与实用场景 | ISR 通知、两个队列、采集处理消费 20 条消息、背压与超时清理 | 场景 3/4，4096 次 FIFO 参考核对 |
| 可验证 MVP | 5 正例、2 故障注入、UART/ELF/哈希/版本证据 | `scripts/rtos.py`、`docs/VALIDATION.md`、CI |
| MoonBit 为主 | 调度和同步通信语义、实际任务体均为 MoonBit | 公开源文件；C/汇编限定硬件胶水与验证仪器 |
| 重复性 | 核对一多 OS 等职责与技术路径；保留同一仓库 | `docs/ECOSYSTEM.md`，不声称生态唯一 |
| 开源与发布 | Apache-2.0，0.4.0 新核心包和 GitHub 完整端口 | `THIRD_PARTY.md`，公开链接与发布核验 |
| 提交次数 | 保留旧 12 条及本轮实质提交，无空提交/改时间 | [公开历史](https://github.com/btlqql/moon-deadline/commits/main/) |

平台验证为 QEMU MPS2 AN385，未使用实体开发板。回执的“实际运行”以目标架构 ELF 裸机执行提供证据；如果评委要求实体板，这部分条件当前未满足。没有把 QEMU 结果写成板测、工业实用部署或硬实时保证。

本轮重新读取了 [官方十一月页面源码](https://github.com/moonbitlang/Hackathon2026/blob/main/src/App.tsx)：MoonBit 为主、公开可追溯提交、可运行示例与必要测试、本期实质增量、开源合规和 AI 可解释；重复、拆分及简单修改不计入。官网具体截止时间仍指向官方通知；本项目回执给出的修改时间为 2026-11-30。用户补充的至少 10 次提交无另列起止时间，按仓库真实历史核对。
